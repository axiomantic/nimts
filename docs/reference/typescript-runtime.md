# TypeScript Runtime API Reference

The TypeScript runtime provides the execution host, memory allocators, and WebAssembly loader for generated modules.

---

## Generated Module Exports

Each module generated by `emitTsGlueFiles` exports:

### `initNimTs(options?: NimTsOptions): Promise<Exports>`
Initializes the WebAssembly module. Subsequent calls return the cached exports object.

```typescript
import { initNimTs } from './synth.js';

const exports = await initNimTs({
  wasmPath: '/wasm/synth.wasm'
});
```

### `getNimTs(): Exports`
Synchronous getter returning the module's exported functions. Throws an error if `initNimTs()` has not been called and awaited.

### `getNimTsModule(): any`
Returns the raw WebAssembly instance exports (`WebAssembly.Instance.exports`).

### `isInitialized(): boolean`
Returns `true` if the WebAssembly module has finished loading and is ready for invocation.

---

## `NimTsOptions`

```typescript
export interface NimTsOptions {
  /** URL or file path to the .wasm binary */
  wasmPath?: string | URL;

  /** Pre-compiled WebAssembly.Module (ideal for AudioWorklet & Web Workers) */
  wasmModule?: WebAssembly.Module;

  /** Raw WebAssembly binary buffer (Uint8Array or ArrayBuffer) */
  wasmBytes?: BufferSource;

  /** Pre-existing WebAssembly.Instance */
  wasmInstance?: WebAssembly.Instance;

  /** Custom WebAssembly imports to merge into the import object */
  imports?: WebAssembly.Imports;
}
```

## `NimTsRuntime` Class (`nimts/runtime`)

The low-level runtime class used internally by generated wrappers:

```typescript
import { NimTsRuntime } from 'nimts/runtime';

const runtime = new NimTsRuntime();
await runtime.init(wasmSource);
```

### Methods

- **`init(source?: string | Uint8Array | WebAssembly.Module): Promise<NimTsExports>`**: Compiles and instantiates the WebAssembly module.
- **`getMemory(): WebAssembly.Memory`**: Accesses the underlying `WebAssembly.Memory` instance. Throws if uninitialized.
- **`passString(str: string): { ptr: number; len: number }`**: Encodes a string into UTF-8, allocates memory in WASM, and writes the bytes.
- **`readString(ptr: number, len: number): string`**: Decodes a UTF-8 string from WebAssembly linear memory.
- **`passBytes(buf: Uint8Array | ArrayBuffer): { ptr: number; len: number }`**: Allocates memory in WASM and copies a byte buffer.
- **`readBytes(ptr: number, len: number): Uint8Array`**: Creates a copy of a byte slice from WebAssembly linear memory.
- **`free(ptr: number): void`**: Frees allocated memory in WASM.
- **`createImportObject(): WebAssembly.Imports`**: Creates the standard WebAssembly imports object providing promise callbacks and the WASI preview1 proxy.

## Projections & Streaming Classes

### `NimTsIterator<T>`
Wraps an active Nim closure iterator in WebAssembly linear memory and implements the ES2015 `IterableIterator<T>` protocol.

```typescript
const iter = exports.countUp(1, 10);

// Use in standard for..of loops
for (const n of iter) {
  console.log(n);
  if (n === 5) break; // Automatically triggers .return() and reclaims WASM memory
}

// Or spread into an array
const arr = [...exports.countUp(1, 5)];
```

- **`next(): IteratorResult<T>`**: Retrieves the next element from the iterator.
- **`return(): IteratorResult<T>`**: Deterministically disposes the iterator slot in WASM and frees heap handles upon early loop termination.
- **`[Symbol.iterator]()`**: Enables native JavaScript iteration.

### `NimTsChannel<T>`
Wraps an asynchronous SPSC wait-free bounded channel and implements the ES2018 `AsyncIterable<T>` protocol.

```typescript
const channel = exports.createEventStream();

// Consume asynchronously
for await (const event of channel) {
  processEvent(event);
}
```

- **`send(item: T): boolean`**: Sends an item into the channel buffer.
- **`recv(): Promise<T | null>`**: Awaits the next item from the channel.
- **`close(): void`**: Closes the channel.
- **`[Symbol.asyncIterator]()`**: Enables native JavaScript `for await..of` iteration.
